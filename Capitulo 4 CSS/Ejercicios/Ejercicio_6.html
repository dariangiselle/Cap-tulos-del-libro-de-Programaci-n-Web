Ejercicio 4.6 de CSS

Instrucción

Escriba una regla de CSS que cambie de color de todos los elementos que contengan el atributo class = "verdeMover" a verde y los desplace 25 pixeles hacia abajo y 15 pixeles a la derecha.


Regla:

.verdeMover { color: green; position: relative; top: 25px; left: 15px; }
