Ejercicio 4.4 Regla de CSS

Hola, aquí se agregó una imagen de fondo que está en la parte inferior de esta pagina con mosaico horizontal. La imagen permanece en su lugar aunque el usuario se desplace hacia arriba o hacia abajo.







Esto se hizo con la regla:











body { background-image: url(imagen_ejerc4/imagen.png); background-position: bottom center; background-repeat: repeat-x; background-attachment: fixed; }




































Como se puede observar, la imagen sí permanece en su lugar
